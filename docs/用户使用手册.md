# DomainToolBS 用户使用手册

| 项目 | 内容 |
|---|---|
| 适用角色 | 超级管理员 / 管理员 / 普通用户 / 审计员 |
| 文档版本 | v1.1（P1–P6 + CA 认证开关 + OU 审计补全） |

> 访问地址由运维提供（默认前端 http://<服务器>:8080）。所有写操作均需对应角色与作用域权限，越权时界面会提示"无权限"。

---

## 1. 登录与初始化

1. 打开前端地址，进入登录页；
2. **首次部署**：若平台无任何账号，点击「首次使用？初始化平台」，设置超级管理员用户名/密码；
3. 使用账号登录，令牌默认 120 分钟有效，过期后重新登录；
4. 登录后右上角显示当前角色标签与全局域选择器。

### 修改自身密码
- 点击右上角用户名 → 「修改密码」；
- 输入原密码、新密码、确认新密码 → 保存；
- **所有角色（含超级管理员）均可在 Web 端修改自身密码**；
- 新密码须满足**复杂度**：长度 ≥ 8，且同时包含大写字母、小写字母、数字、符号（如 `!@#$%^&*`）；
- 新密码**不得与当前密码相同**，也**不得与最近 3 次使用过的密码相同**；
- 超级管理员若忘记密码，需联系运维在**服务器侧**重置（无法通过 Web 找回）。

---

## 2. 全局域切换

- 顶部下拉选择「当前管理域」；
- 切换后，用户/组/计算机/组织/OU/批量等页面自动按所选域重新加载；
- 未选域时相关页面给出提示，写操作被禁止。

---

## 3. 域配置

入口：左侧「域配置」（超管与管理员可见；普通用户只读且凭据脱敏）。

- **新建域（管理员可用）**：填写名称、域控地址、LDAPS 端口、Base DN、绑定账号/密码、说明；
  - 若名称或 Base DN 已存在，系统提示"该域已存在，请由超级管理员分配"，不能重复新建；
  - 管理员成功新建后，**该域自动分配给本人管理**（整域全写权限）；
- **连通性测试**：填写后点击「连通性测试」验证域控可达与账号权限；
- **编辑 / 删除**：超管可管理任意域；管理员仅可管理已授权（含自建）的域；
- **域信息**：查看域概览（用户数、计算机数、OU 数等）。
- **CA 认证开关（仅超级管理员可见）**：每个域可开启/关闭 CA 认证，切换即时生效。
  - 开启（默认）：按域控证书信任状态校验，证书未通过（缺 CA / 过期 / 校验失败）时，非超管的写操作会被暂停；
  - 关闭：该域不启用任何 CA 限制，管理员可自由操作（适合可信内网 / 测试域）；
  - 管理员与普通用户看不到该开关，无法切换。

---

## 4. 组织与用户

入口：左侧「组织与用户」。

### 4.1 OU 树
- 左侧 OU 树展示层级结构，点击节点切换范围；
- 支持新建子 OU、删除 OU（需写权限与作用域）。

### 4.2 用户查询
列表支持多种过滤：
- 关键字（登录名/姓名/邮箱）；
- **OU 归属**（树选择器，默认全域）；
- 状态（启用/禁用）；
- 锁定（是/否）。

### 4.3 用户操作（需写权限且在作用域内）
- 新建用户（指定 OU、登录名、密码等）；
  - 初始密码须满足**复杂度**：长度 ≥ 8，含大写、小写、数字、符号；
  - UPN 选填（格式 `登录名@域后缀`，如 `zhangsan@corp.local`），留空时不自动生成；
- 启用 / 禁用；
- 重置密码（可勾选"下次登录必须修改"）；
- 解锁（解除账户锁定）；
- 移动到其他 OU；
- 查看/编辑用户属性。

---

## 5. 用户组

入口：左侧「用户组」。
- 查看用户组列表与成员；
- 成员管理支持分页/分片（适配大集团）；
- 新建/删除组、增删成员（需写权限与作用域）。

---

## 6. 计算机

入口：左侧「计算机」。
- 列表过滤：**OU 归属**、关键字（计算机名）、状态（启用/禁用）；
- 操作（需写权限）：
  - 启用 / 禁用；
  - 移动到 OU；
  - 删除。

---

## 7. 批量任务

入口：左侧「批量任务」（超管与管理员可见）。

### 7.1 操作类型
顶部单选切换：**新增用户 / 删除用户 / 修改用户**。

### 7.2 新增用户
1. 点「下载模板」获取 CSV；
2. 按模板填写（支持 UTF-8 或 Excel 默认 GBK/GB18030 编码）；
3. 选「目标 OU」→「选择 CSV」→「开始执行」；
4. 系统后台逐行创建，结果见任务明细。

### 7.3 删除用户
- 模板仅需 `sAMAccountName` 一列；
- 上传后逐行定位并删除（每行做作用域校验）。

### 7.4 修改用户
- 模板含 `sAMAccountName`，可选列：`displayName`、`userPrincipalName`、`mail`、`department`、`title`、`telephoneNumber`、`description`、`password`、`must_change_next_logon`、`enabled`；
- 仅填写的列会被更新；密码列填写则重置密码（同样须满足复杂度要求，且不可与当前/最近 3 次密码相同）。
- `userPrincipalName` 为选填 UPN（`登录名@域后缀`），不自动生成。

### 7.5 任务明细与导出
- 「批量任务」列表展示任务类型、状态、总数/成功/失败；
- 点击「详情」查看每行对象、状态与失败原因；
- 「导出当前域用户」可将现有用户导出为 CSV（供修改后回灌）。

---

## 8. 审计日志

入口：左侧「审计日志」（超管/管理员/审计员可见）。
- 记录**域对象（用户 / 用户组 / 计算机 / OU）的写操作**（创建/更新/删除/启用禁用/移动 OU/解锁/重置密码/组成员增删）与**批量任务**；
- 支持按域、动作、时间过滤；
- 支持导出；
- 审计员仅能访问此页面；
- 说明：当前版本**不记录**登录、平台账号自身改密、平台账号（超管/管理员/用户/审计员）增删改、授权(scope)变更。

---

## 9. 授权管理（仅超级管理员）

入口：左侧「授权管理」。
- 查看管理员列表；
- **仅 `管理员` 角色可被委派授权**：勾选权限矩阵（用户/组/计算机/OU 的写、删除、重置密码等），设置作用域（整个域根 或 指定 OU 子树），授权取并集；
- **普通用户 / 审计员**使用系统内置默认权限（普通用户=全域只读、审计员=仅审计），不在此展示授权矩阵、也不可配置；
- 超级管理员不可被配置作用域。

---

## 10. 账户管理（仅超级管理员）

入口：左侧「账户管理」。
- 管理 `admin`/`user`/`auditor` 账号（新建、编辑、禁用、删除）；
- **禁止通过界面创建/编辑/删除/设为超级管理员**，禁止删除自身；
- 超级管理员账号只能通过服务器侧脚本维护（见部署/运维文档）。

## 12. 常见问题

**Q1：连不上域控？**
确认域控 LDAPS(636) 可达、绑定账号有相应委派权限、证书被信任；可在「域配置」点连通性测试排查。

**Q2：写操作提示无权限？**
当前账号作用域未覆盖目标 OU/权限，请联系超级管理员在「授权管理」调整。

**Q3：批量某行失败？**
查看该任务的明细 message；常见为"用户不存在""越权""密码策略不满足"。

**Q4：忘记超级管理员密码？**
无法通过 Web 找回，需运维在服务器侧执行 `reset_superadmin.py` 脚本重置。

**Q5：CSV 上传报错编码？**
请用 UTF-8（带/不带 BOM）或 GBK(GB18030) 保存。
